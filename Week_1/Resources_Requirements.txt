8.1 Hardware Specifications

    1. Processor: Multi-core 64-bit CPU (Intel Core i5/i7 or AMD Ryzen 5/7, 4+ cores).
    2. Memory (RAM): Minimum 8 GB (16 GB recommended for hyperparameter search).
    3. Storage: At least 5 GB of free disk space for datasets, virtual environments, and serialised artefacts.

8.2 Software & Libraries Stack

    1. Core Language & Runtime: Python 3.10+
    2. Data Manipulation: pandas (≥2.0), numpy (≥1.24)
    3. Visualisation: matplotlib (≥3.7), seaborn (≥0.12)
    4. Machine Learning Engine: scikit-learn (≥1.3)
    5. Model Serialisation: joblib (≥1.3)
    6. API Deployment: FastAPI (≥0.100), uvicorn (≥0.22), pydantic (≥2.0)
    7. Version Control: Git & GitHub for codebase tracking and mandatory submission links.
